10. Observations & Recommendations

3 WARNINGS
!
24 of 33 apps still on Manual provisioning
Apps like Datadog, Figma, Canva, AWS, OpenVPN, DocuSign etc. have no automation. Recommend evaluating SCIM/SSO connectors for high-license-count apps (Datadog 35, Canva 32) to reduce offboarding risk.
!
Jenkins (A-27) at 0/20 license utilization
Jenkins has 20 licensed seats but 0 used. CI/CD pipeline may be unused or users access it without license assignment. Recommend auditing active usage.
!
In-memory MongoDB — data resets on server restart
The app uses mongodb-memory-server so all provisioning updates (SCIM connectors, etc.) will be lost if the server is restarted. For production, migrate to a persistent MongoDB instance.
ℹ️ All warnings are data/infrastructure observations. No functional defects were found in the application. All 34 checks PASS.
