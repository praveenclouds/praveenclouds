How to connect your Identity Provider
1. Enable the SCIM Server using the sidebar toggle, then click Save Changes
2. Copy the SCIM Base URL and Bearer Token shown above
3. In your Identity Provider admin console, open SCIM / Provisioning settings and paste both values
4. Map user attributes — userName → Email name.givenName → First name name.familyName → Last name active → Account status
5. Enable provisioning — Terzo will automatically create and deactivate users on join / leave events
